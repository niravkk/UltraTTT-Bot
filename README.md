# UltraTTT-Bot
Bot for the Ultimate tictactoe (variation of ticatactoe). Uses monte carlo tree search and pygame.

ultra_pygame.py contains bunch of helper function and classes. 
rawNewb_pygame.py contains the monte carlo and actual pygame loop and stuff.
